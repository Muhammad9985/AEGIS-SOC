Host Isolation Kill-Switch

Click [🚨 ENGAGE HOST ISOLATION]: Windows Defender Firewall drops all external inbound and outbound packets. Whitelists local loopback (127.0.0.1) and AEGIS dashboard port (8000) so your management session stays alive. Click [RESTORE NETWORK ACCESS] when sanitized.

ENGINE 2

Shannon Entropy Shield

Computes Shannon entropy (0.0 to 8.0) of written buffers. Plaintext is 3.0-4.5; encrypted ransomware writes spike above 7.20. When detected, the engine suspends process execution in < 15ms and blocks vssadmin delete shadows.

ENGINE 3

EDR Anti-Tamper Shield

Continuously intercepts attempts to blind security tools (e.g. wevtutil cl Security, Set-MpPreference -DisableRealtimeMonitoring, sc stop Sysmon). Immediately terminates the offending caller before execution succeeds.

ENGINE 4

Binary Disarmament & Vault

Calculates SHA-256 cryptographic hash, moves malicious executables into data/quarantine/, applies strict NTFS ACL execution denial (icacls /deny Everyone:(X)), and sanitizes registry autostart Run keys.

11. TROUBLESHOOTING & FREQUENTLY ASKED QUESTIONS

Why does Host Isolation require Administrator privileges?
Modifying Windows Defender Firewall rules via netsh advfirewall requires elevated local privileges. Ensure the terminal or launcher starting AEGIS is executed as Run as Administrator.
How do I install Sysmon in 1 single command?
Open an elevated PowerShell prompt and run:
winget install Microsoft.Sysinternals.Sysmon
Then start Sysmon with SwiftOnSecurity's recommended config.
Where are database records and forensic dumps saved?
All telemetry and audit records reside in data/siem.db (SQLite). Process memory snapshots reside in data/vault/. Quarantined binaries are disarmed inside data/quarantine/.
Does AEGIS-SOC slow down my computer?
No. AEGIS-SOC is designed with asynchronous Python (FastAPI/asyncio) and background thread pools with average CPU consumption under < 1% during standard baseline operation.
Can AEGIS run in an air-gapped / offline network?
Yes! AEGIS-SOC is 100% self-contained and local. It requires zero cloud connectivity for telemetry collection, Sigma correlation, host isolation, or forensic vaulting.
How is state preserved between agent sessions?
The codebase uses codebase-memory-mcp with an indexed knowledge graph and persistent Architecture Decision Records (ADRs) stored in .codebase-memory/ so the system state is remembered across sessions.
